# Presentación

Este **Manual de Operación** reúne, en un único documento versionado, qué es el Observatorio de
amplificación (ámbito FIMI), cómo se especifica y se calcula la señal, de qué fuentes se nutre, cómo
se gobierna y se valida, cómo se opera el día a día, cuánto cuesta y qué límites tiene.

**Cómo leerlo.** Los capítulos 1–4 describen *qué mide y cómo*; 5–8, *gobierno, validación,
atribución y trazabilidad*; 9–10, *operación y costes*; el 11 es el **glosario**.

**Cómo se mantiene.** El documento se genera desde **Markdown versionado en el repositorio**
(`docs/manual/` + los `docs/*.md` de cada capítulo) con `detection/gen_manual.py`. Para ampliarlo o
corregirlo se edita el Markdown y se regenera el PDF; no se edita el PDF a mano.

**Encuadre (innegociable).** El Observatorio mide **amplificación** (varias cuentas repiten lo mismo
a la vez). **No atribuye** autoría, intención ni dimensión estatal, y **no confirma campañas**:
una banda alta es amplificación medida, **nunca** coordinación confirmada. El «no» también es un
resultado.
