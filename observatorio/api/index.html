API pública

Solo lectura. Titulares capturados, fuente, fecha y enlace. No confirma hechos ni atribuye intención.

Versión de software 0.1.0 · actualización de datos cada 30 minutos.

Base: https://fimi.viajeinteligencia.com/api/observatorio/v1/
Sin autenticación. Sin escritura. Sin datos personales.

Endpoints

EndpointQué devuelve
GET /itemsTitulares; filtros topic, source, q, since, until, limit, offset.
GET /topicsTemas y número de registros.
GET /sourcesSalud de las 75 fuentes.
GET /healthEstado de API, datos y fuentes.
GET /export.csvCSV de los filtros aplicados.
GET /export.ndjsonNDJSON de los filtros aplicados.
GET /openapi.jsonEsquema OpenAPI básico.

Ejemplos

Últimos titulares de Infraestructuras

curl "https://fimi.viajeinteligencia.com/api/observatorio/v1/items?topic=infraestructuras_espana&limit=10"

Exportar Frontera Sur a CSV

curl -o frontera-sur.csv "https://fimi.viajeinteligencia.com/api/observatorio/v1/export.csv?topic=frontera_sur&limit=200"

Buscar “Ceuta”

curl "https://fimi.viajeinteligencia.com/api/observatorio/v1/items?q=Ceuta&limit=20"

Campos

  • id: identificador estable.
  • topic: tema.
  • title: titular publicado.
  • url: enlace.
  • source: medio u organismo.
  • published: fecha de publicación.
  • fetched: fecha de captura.

Límites

  • Máximo 200 registros por petición.
  • Los datos son titulares, no hechos verificados.
  • No se ofrece escritura, edición ni comentarios.
  • La lista de fuentes puede cambiar; consulta /sources.
