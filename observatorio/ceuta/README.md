# Observatorio Ceuta y Marruecos

Primera versión local, sin desplegar.

## Regenerar

```bash
cd /home/miguelc/fimi_local/repo
python3 observatorio/ceuta/gen_ceuta.py
```

Genera `observatorio/ceuta/index.html`.

## Datos reutilizados

- `data/caso_frontera_sur_hibridos/episodios_curados.json`: 6 fichas curadas.
- `docs/casos/ceuta-v1.json`: auditoría V1 fechada 30-jul→21-sep-2026.

## Límites

- No hay fuente primaria localizada para los episodios militares.
- Las fuentes de las fichas son medios; algunas URLs son portada de medio.
- No se atribuye organización, intención ni operación de influencia.
- No se presentan las afirmaciones como hechos confirmados.
