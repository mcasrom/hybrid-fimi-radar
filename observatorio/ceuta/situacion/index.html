8. Qué no se puede concluir

  • Una ficha con varias fuentes no tiene varias fuentes independientes: los enlaces se clasifican por papel, no por independencia editorial.
  • Un titular no es una incursión, un contrato ni una capacidad desplegada.
  • La coincidencia temporal entre migración, movimiento naval y cobertura no demuestra coordinación ni intención.
  • No se afirma que las publicaciones sean falsas: se indica qué está documentado y qué falta.
  • La ausencia de una operación de influencia no se deduce de estos datos; tampoco se confirma.
Resumen honesto. Hay cobertura periodística suficiente para describir un debate y varias hipótesis; no hay evidencia primaria suficiente para confirmar las afirmaciones, una intención hostil ni una operación de influencia.
