Método

Este registro documenta lo que se publica y lo que puede comprobarse. No convierte una publicación en un hecho.

Qué se registra

  • Afirmaciones publicadas: título, medio, fecha y enlace.
  • Episodios: fecha, ciudad, convocantes citados, demandas y estado.
  • Calendario: fechas oficiales del BOE.

Cómo se obtiene

La selección es manual a partir de fuentes públicas. El calendario se extrae automáticamente del real decreto del BOE y se valida. No hay captura automática de acontecimientos ni confirmación automática.

Estados

  • Secundaria: solo prensa o referencia secundaria.
  • Documentada: existe un documento oficial o declaración directa.
  • Pendiente: falta fuente primaria o contraste.
  • No consta: no hay información suficiente.

Qué no se hace

  • No se atribuye autoría ni intención.
  • No se confirma un acto por su fecha prevista.
  • No se usan clústeres, bandas, scores ni métricas internas.
