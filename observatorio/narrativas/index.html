Narrativas: código y muestra

Una publicación puede tener más de un marco, pero aquí se codifica un marco dominante por pieza. La asignación es manual y revisable; el script no usa IA ni reglas de palabras clave para etiquetar.

Estado: sin codificar. Muestra: 60 publicaciones. Descarga: muestra.csv.

Cómo codificar

  1. Descarga muestra.csv.
  2. Rellena narrativa con un código del tema o déjalo vacío si no encaja.
  3. No cambies id, topic ni titular.
  4. Devuelve el CSV corregido; se valida y se cuentan los códigos.

Una publicación sin marco no es un error. Un mismo titular en medios distintos sigue siendo una publicación distinta.
